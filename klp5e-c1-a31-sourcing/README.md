# klp5e-c1-a31-sourcing — Activity A3.1, source a part you have never used

The files for Course 1, Module 3, activity A3.1. You take one manufacturer part number through
the sourcing tree, check the result against the datasheet, and make the project self-contained.

| File | What it is | When to open it |
|---|---|---|
| [`TASK.md`](TASK.md) | The part, the datasheet link, and the steps | First |
| [`record-sheet.md`](record-sheet.md) | The sheet you fill in as you work | While you work |
| [`worked-solution/`](worked-solution/) | A finished KiCad project and its `SOLUTION.md` | **Last**, after your record sheet is finished |

The worked solution gives the answer away. Leave it closed until your own record sheet is
complete, then compare the two. Where you disagree with it, measure again before deciding who
is right.

The Espressif library files in `worked-solution/esp32-c6-sourcing/Libraries/` are
redistributed under Espressif's licence, CC-BY-SA 4.0 with the KiCad-library exception. The
licence is kept beside them as `LICENSE-Espressif.md`.
