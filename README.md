# KLP 5e — Course 1: Your First PCBs — project files

Companion project files for *KiCad Like a Pro, 5th Edition*, Course 1 ("Your first
PCBs"). Each hands-on project is captured as a series of numbered stages, one per build
step in the course, so you can start from any point or check your own work against a
known-good result.

Clone this repository, or download the stage folder you need, open it in KiCad's project
manager, and carry on from there.
