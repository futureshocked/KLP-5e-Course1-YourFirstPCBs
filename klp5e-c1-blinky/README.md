# klp5e-c1-blinky — the blinker, staged

The blinker board from Course 1, Module 1, captured as one folder per build step. Stage N
is the project exactly as it stood at the end of the lecture that produced it, and the
start of the next one.

Open a stage in KiCad's project manager and carry on from the next lecture, or use one as
a restart point if a step went wrong.

| Stage | State | Lecture |
|---|---|---|
| `00-project-created` | Project created, sheet blank | L1.1 |
| `01-symbols-placed` | Symbols placed, unannotated, nothing wired | L1.2 |
| `02-annotated` | Every designator assigned | L1.3 |
| `03-values-set` | All values set | L1.4 |
| `04-wired` | Fully wired | L1.5 |
| `05-footprints-assigned` | Every symbol footprinted | L1.6 |
| `06-erc-clean` | ERC clean, schematic complete | L1.7 |
| `07-parts-imported` | Parts imported to the board | L1.8 |
| `08-bearings` | Board editor set up | L1.9 |
| `09-outline-drawn` | Board outline drawn | L1.10 |
| `10-parts-placed` | Components placed | L1.11 |
| `11-routed` | Tracks routed | L1.12 |
| `12-ground-poured` | Ground pour added | L1.13 |
| `13-silkscreen-added` | Silkscreen text added | L1.15 |
| `14-plotted` | Finished board, plotted to `Gerbers-blinky/` | L1.16 |

`14-plotted` is the finished board. If you build the blinker yourself in activity A1.1,
compare your result against this stage, not against the exact steps that got you there.
